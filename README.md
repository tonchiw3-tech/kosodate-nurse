
# 子育てナース

## 毎日の看護を、未来のキャリアに。

### 子育てと看護の毎日に、やさしい支えを。

## アプリ概要

「子育てナース」は、子育て中の看護師を対象にしたWebアプリです。

仕事・子育て・学び・予定・情報収集・人とのつながりをひとつの場所で確認しながら、日々の看護経験を記録し、振り返り、これからの学びやキャリアにつなげることを目指しています。

仕事や家庭の予定に追われる中でも、その日に感じたことや学んだことを残し、自分らしい働き方や将来のキャリアを考えるきっかけをつくるために制作しています。

## コンセプト

**子育てナースの毎日を、もっと自分らしく。**

仕事も、子育ても、ひとりで抱え込まない。
毎日に役立つ情報と、学び・つながりを届けるアプリを目指しています。

## 主な6つの機能

トップページには、現在次の6つの機能カードを配置しています。

### 1. 今日を残す

その日の看護経験や気づきを記録し、日々の実践を振り返る機能です。

- 日付を選んで記録
- できたこと
- 学んだこと
- 次に活かしたいこと
- 看護経験から学習キーワードを確認

忙しい日でも、短時間で経験を残せることを目指しています。現在のデモ版では、入力した記録をブラウザ内に保存できます。音声入力・音声からの文字変換は今後実装予定です。

### 2. 今日から学ぶ

日々の看護経験を次の学びにつなげる機能です。記録から得られたキーワードを確認したり、学びたい項目を検索・追加したりできます。

学習テーマの例：訪問看護、外来看護、急性期看護、慢性期看護、看護技術、医療安全、自分で追加した項目

### 3. わたしの予定

仕事・家庭・研修・学校行事などの予定を、まとめて確認するカレンダー機能です。

現在のデモ版では、日付をクリックして予定を入力し、ブラウザ内に保存できます。前期（4月〜9月）・後期（10月〜3月）・年間表示など、年度単位で把握しやすい表示への発展を想定しています。

### 4. わたしのキャリア

研修、セミナー・学会、看護ラダー、看護協会、資格、今後身につけたいスキルなど、これまでの経験や今後の学びを整理する機能です。

日々の経験を「その日の仕事」で終わらせず、将来のキャリアを考える材料として蓄積することを目的としています。

### 5. 看護の最新情報

研修、制度、資格、働き方、医療安全、看護技術など、看護師に役立つ情報を確認する機能です。現在は記事タイトル・概要・リンクなどを確認するデモ構成です。RSSやAPIによる情報の自動取得は将来構想です。

### 6. みんなとつながる

仕事と子育てを両立している看護師同士が、経験や工夫を共有する機能です。仕事と育児、キャリア、復職、夜勤、勉強などをテーマに、自分に合った働き方を考えられる場を目指しています。

## トップページの構成

| 上段 | 下段 |
| --- | --- |
| 今日を残す | わたしのキャリア |
| 今日から学ぶ | 看護の最新情報 |
| わたしの予定 | みんなとつながる |

**今日の経験 → 学び → 予定 → キャリア → 最新情報 → 人とのつながり**

毎日の小さな経験を起点に、学びや情報収集、予定の整理、将来のキャリア、人との交流へと視野を広げられる構成です。

## このアプリで向き合いたい課題

子育て中の看護師は、状況によって次のような難しさを感じることがあります。

- 自分の看護経験を振り返る時間を取りにくい
- 勉強したくてもまとまった時間を確保しにくい
- 研修や資格などの情報を探す時間がない
- 子育てなどのライフイベントで、キャリアが止まったように感じることがある
- 今後の働き方を考える時間が少ない
- 同じ状況の看護師と情報交換する機会が少ない
- 家庭・仕事・研修などの予定管理が複雑になりやすい

「経験を残す」「学びにつなげる」「情報を得る」「予定を整理する」「キャリアを考える」「人とつながる」ことを、ひとつの場所で行えるサービスを目指しています。

## 現在の実装

現在は、Webブラウザで操作できるデモ版として開発しています。

- トップページから6つの機能ページへ移動できる構成
- 看護経験の入力・保存と、記録に関連する学習キーワードの表示
- 学習キーワードの検索・追加
- 仕事・家庭・学びの予定を入力できるカレンダー
- 研修・学会・資格などのキャリア情報の入力・保存
- 看護に関する情報を確認するページ
- 看護師の経験や工夫をテーマ別に見るコミュニティページ
- PCとスマートフォンの両方で利用しやすいレスポンシブデザイン
- デモ版の入力データをブラウザの `localStorage` に保存

`localStorage` のデータは、その端末・そのブラウザ内で利用するデモ版の仕組みです。複数端末での同期や、サービスとしての認証・アクセス制御を実現するものではありません。

## 制作背景

このアプリは、職業訓練校でのWeb制作・アプリ開発学習の課題の一環として制作しています。訓練では、HTML、CSS、JavaScript、Git、GitHub、AIを活用した開発などを学んでいます。

学んだ技術を使うだけでなく、看護師としての実務経験をもとに、「実際の看護現場や看護師の働き方に関係する課題を、ITでどのように改善できるか」を考えながら企画・制作しています。

単なる提出課題で終わらせず、今後も機能追加や改善を続け、実際に役立つサービスへ発展させていきたいと考えています。

## 開発の目的

テーマは、**「毎日の看護経験を、自分の未来につなげるにはどうしたらよいか」**です。

看護師としての経験と、職業訓練で学んだWeb制作・IT・AI活用の知識を組み合わせ、子育てなどのライフイベントを経験しても、これまで積み重ねてきた経験や学びを見失わず、自分らしいキャリアを考え続けられるサービスを目指しています。
