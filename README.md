
# 子育てナース

毎日の看護を、未来のキャリアに。

## 概要

「子育てナース」は、子育て中の看護師が、
日々の看護経験を記録し、振り返り、学びにつなげるためのアプリです。

## 主な機能

- 音声で看護日記を記録
- カレンダーで振り返り
- 1日1つ、おすすめ看護記事を表示

## 対象

子育てをしながら働く看護師

## 目的

子育て中は、研修参加や学習の時間を確保しにくいことがあります。

そこで、毎日の看護実践を記録し、
日々の経験を看護師としての成長やキャリアにつなげることを目的としています。

## 使用技術

- HTML
- CSS
- JavaScript
